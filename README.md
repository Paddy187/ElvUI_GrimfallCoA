Grimfall ElvUI_CoA

Base: Grimfall ElvUI 6.3-CoA-Fix1

Frame Shadows (Skins → Shadows)

Configurable outer shadow (color, size) for:
action bars, unit frames and group frames (per unit)
cast bars, aura icons, player buffs/debuffs, tooltips and data bars
minimap, panels, bags, loot, threat bar and nameplates
Separate switches for the Power Stack and the Energy/Rage/Mana/Runic bars

Unit Frames

Information Panel: top position, “Outside Portrait”, own texture and color
Portrait: “CoA Class” style, detach with its own mover, auto width
Per-unit castbar:
texture, font, text color
“Icon Inside Portrait”
X/Y offset for spell name and time
Own textures for power and runes; runes get an X/Y offset
Combat, rest and RL/ML icons: preview, “Material” textures, size and offset

Gradients (Base → Gradient color)

Health by class (default and CoA classes), reaction and special states; coloring by health thresholds
Power, cast bars, aura bars, runes and combo points
Energy/Rage/Mana/Runic bars, plus the XP, pet XP and reputation bars
Threat bar, loot rolls and the tooltip health bar

Power Stack (UnitFrames → Player → Power Stack)

Fully configurable:
Auto/Show/Hide per resource
size, position and mover
border, text, font, colors, gradient
Disabled by default; while it is enabled, the Player bars it replaces are greyed out with a note

Threat Bar

Detachable with its own mover, size, texture, font, custom colors with gradient, preview

Nameplates

Preview shows the cast bar with a test cast
Cast bar text X/Y offset

Misc

Movable Blizzard windows
Fog of war reveal on the world map
Minimap Button Frame
Configurable top/bottom panel
Objective tracker: width, font, line spacing
New fonts (AvantGarde LT, Gotham XNarrow Ultra) and the “CoA Clean” texture
